# ミセル（micelle）モックアップ 完全版

コワーキングスペース milk のつながりから生まれた、中標津の共助プラットフォーム。

## デモ

**👉 https://okudatamiobanzai-web.github.io/micelle-mockup/**

スマホ表示に最適化。PCの場合はデベロッパーツール（F12）でモバイル表示推奨。

## コンセプト

- **乳化のメタファー**: 水（困りごと）× 油（スキル）× 界面活性剤（信用） = 共助コミュニティ
- **誰もがつなぎ役**: milk運営だけでなく、ユーザー同士が人を紹介できる
- **活動が見える化される**: 完了後のレポートがSNSのようにタイムラインに流れる

## 実装済みの全画面・機能

### ホーム（掲示板）
- タイムライン表示（募集中 + 完了レポートが混在）
- **3ビュー切替**: リスト / マップ / カレンダー
- マップビュー: Google Maps連携モック、案件がピン留め表示
- カレンダービュー: 日付ストリップ + 日別グループ表示
- 「📋 完了」タブでアーカイブ閲覧
- コンセプトHero Banner（ロゴタップで再表示）

### 投稿フロー（7ルート完全実装）
- 🚗 **送迎**: 出発地/到着地をGoogleマップで選択 → 距離自動計算 → **実費自動計算（@15円/km）** → 実費のみ固定
- 👶 **子ども**: 年齢選択 → カレンダー日時 → 緊急連絡先 → 安全案内（複数面談制）
- 👴 **高齢者**: 困りごと選択 → マップ場所 → カレンダー日時 → 介護保険対象外の明示
- 🔨 **作業**: 作業種類 → マップ場所 + カレンダー日時 → 報酬設定
- 🎨 **制作**: 制作種類 → 詳細 + カレンダー納期 → 著作権案内 → 報酬
- 💬 **相談**: 分野選択 → 状況記入 → 免責表示 → 無償固定
- 🏠 **暮らし**: 困りごと → マップ + カレンダー → 報酬

### 詳細画面
- コメント欄（紹介カード付き）
- 「🙋 手伝いたい」応募ボタン + 「🔗 紹介」ボタン
- OGP/シェアモーダル（LINEプレビュー風）

### 紹介機能
- 誰でも人を紹介できる（milk運営だけでなくユーザー同士）
- ミセル内メンバー / ミセル外の人の2モード
- 紹介コメント必須（「なんとなく紹介」を防止）
- 紹介チェーンの記録・表示
- 「○○の紹介」バッジ

### 活動レポート
- 完了案件に写真+テキストのリッチレポート
- 依頼者の振り返り + お手伝い側のレポートが並列
- 写真は自由（枚数・内容制限なし）、横スクロール
- **レポート入力画面**: テキスト + 写真追加 + 所要時間 + リアルタイムプレビュー

### プロフィール
- Orbビジュアル（活動量で自動計算されるドット）
- 統計バー: お手伝い / 依頼 / 紹介 / タグ
- 「プロフィール」と「活動」の2タブ
- 活動タブ: 過去の完了レポートが写真付きで一覧
- タップでレポート詳細に遷移
- お気に入り♥ボタン

### タグを贈る
- 12種の既定タグ + 自由入力
- タグを贈る/スキップの選択
- 贈ったタグはプロフィールに表示

### マイページ
- 自分のプロフィール + 統計
- マッチ済み案件に「📋 レポートを書く」ボタン
- 活動履歴 / お気に入りの2タブ

### 応募フロー
- 自分のプロフィール表示 + メッセージ入力

### その他
- 通知ベル（未読バッジ）
- Googleマップ場所選択モーダル（検索 + タップ選択）
- カレンダー日付選択モーダル
- 時間セレクター（15分刻み）
