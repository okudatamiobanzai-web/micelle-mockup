# ミセル（micelle）モックアップ v10

コワーキングスペース milk のつながりから生まれた、中標津の共助プラットフォーム。

## デモ

**👉 https://okudatamiobanzai-web.github.io/micelle-mockup/**

スマホ表示に最適化されています。PCの場合はブラウザのデベロッパーツール（F12）でモバイル表示に切り替えてください。

## コンセプト

- **乳化のメタファー**: 水（困りごと）× 油（スキル）× 界面活性剤（信用） = 共助コミュニティ
- **誰もがつなぎ役**: milk運営だけでなく、ユーザー同士が人を紹介できる
- **活動が見える化される**: 完了後のレポートがSNSのようにタイムラインに流れる

## 実装済みの画面

- 掲示板（タイムライン）+ 完了アーカイブタブ
- 7カテゴリの投稿フロー（送迎/子ども/高齢者/作業/制作/相談/暮らし）
- 紹介モーダル（ミセル内/外の人を紹介）
- 応募フロー
- 人物一覧 + プロフィール詳細（活動履歴タブ付き）
- 活動レポート詳細ページ（写真・振り返り・感想）
- 活動レポート入力画面
- マイページ（活動履歴/お気に入り）
- 通知画面
- コンセプトビジュアル（Hero Banner）

## 技術スタック（モック）

- React 18 (CDN)
- Babel Standalone (CDN)
- インラインCSS（デザイントークンベース）
- 自己完結HTML 1ファイル
